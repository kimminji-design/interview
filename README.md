# 면접 준비 노트

빌드 없이 GitHub Pages에서 실행되는 개인 면접 노트입니다. 편집과 연습을 분리하며, 기업별 JSON을 GitHub Contents API로 저장합니다.

## 사용

- **질문 관리**: 검색, 질문·답변·키워드 통합 편집, 중요 표시, 준비 상태, 다중 선택, 순서 변경.
- **전체 연습 / 중요 질문 / 실전 연습**: 같은 질문 데이터를 공유합니다. 중요 표시는 답변의 요약본을 별도로 생성하지 않습니다.
- **기업 추가**: 빈 노트로 시작한 뒤 다른 기업에서 필요한 질문만, 또는 답변까지 선택 복사합니다. 원본 회사명은 자동 치환하지 않습니다.
- **가져오기 / 내보내기**: 기업 선택 내보내기, 가져오기 미리보기, 기존 기업별 사본 생성 또는 명시적 교체. 다른 기업은 유지합니다.
- **키워드 추천**: 외부 AI를 호출하지 않고 답변 안의 용어·인용구·수치를 후보로 보여줍니다. 기존 키워드를 자동 덮어쓰지 않습니다. 답변 문구 선택 추가와 빈 키워드 일괄 검토도 지원합니다.

## 기기 간 저장

1. 사이트의 **연결 설정**을 엽니다.
2. GitHub Fine-grained personal access token을 발급합니다. 저장소는 `interview`만, 권한은 `Contents: Read and write`만 선택합니다.
3. 사이트의 연결 키 입력란에 키를 넣고 공개 저장에 동의합니다. **키는 소스 코드, JSON, 채팅에 넣지 않습니다.**
4. 개인 기기에서는 **이 기기에서 연결 유지**를 선택하세요. PC와 휴대폰의 각 브라우저에서 한 번씩 연결하면 다음 방문에도 자동 연결됩니다. 같은 유효한 키를 사용할 수 있으며 매번 새로 발급할 필요는 없습니다.
5. 연결 후 저장은 약 2초 뒤 자동 진행됩니다. `지금 동기화`로 즉시 저장할 수도 있습니다. 다시 방문하거나 다른 앱에서 돌아올 때, 네트워크가 복구될 때에도 최신 내용을 확인하고 남은 수정본을 동기화합니다.
6. 읽기만 하는 기기는 키 없이 최신 내용을 불러옵니다. 양쪽에서 같은 답변을 다르게 수정했다면 기존 충돌 확인 화면에서 선택합니다.

연결 유지 옵션은 기본 해제입니다. 선택하면 키를 현재 브라우저의 별도 localStorage 항목 `interviewGitHubConnection.v1`에 저장합니다. 이 값은 질문·답변, 백업, JSON 내보내기, GitHub 업로드에 포함되지 않습니다. 브라우저 저장소는 암호화된 비밀 저장소가 아니므로 개인 기기에서만 사용하세요. 연결 해제 시 저장된 키를 삭제합니다. 키 만료·폐기 또는 사이트 데이터 삭제 후에는 다시 연결해야 합니다. 옵션을 선택하지 않으면 기존처럼 현재 페이지 메모리에서만 사용합니다. GitHub 로그인 쿠키나 입장 비밀번호는 쓰기 권한을 대신하지 않으며 별도 OAuth 서버는 사용하지 않습니다.

**공개 범위:** 현재 저장소는 공개입니다. `interview-data.json`과 Git 이력도 공개되며, 프런트엔드 입장 화면은 접근제어가 아닙니다. 기밀 데이터를 저장하지 마세요.

## 데이터 보존과 충돌

- 기존 `interviewCompanyData.v1` 데이터는 읽어서 가져오되 기존 키를 변경하지 않습니다.
- 새 캐시는 `interviewWorkspace.v2`에 보관합니다. 선택 기업은 기기별 설정입니다.
- 처음 연결할 때 양쪽 데이터가 다르면 사용자에게 기준을 묻습니다. 같은 기업은 선택한 쪽을 사용하고, 한쪽에만 있는 기업은 함께 유지합니다. 자동으로 덮어쓰지 않습니다.
- 이후에는 마지막 공통 버전을 기준으로 항목별 병합합니다. 같은 항목을 다르게 수정하거나 삭제/수정이 겹치면 양쪽 값을 비교해서 선택합니다.
- GitHub 쓰기는 최신 파일 SHA를 사용합니다. 충돌이나 네트워크 오류가 나면 로컬 수정본을 유지하고 오류를 표시합니다.
- 동기화·삭제·가져오기 전 최대 4개의 기기별 백업을 보관합니다. `가져오기 / 내보내기`에서 내려받을 수 있습니다.
- 같은 브라우저의 다른 탭에서 변경하면 오래된 탭의 편집을 중단하고 새로고침을 안내합니다.

## 구조

- `index.html`, `workspace.css`, `workspace.mjs`: 편집·연습 UI
- `core.mjs`: 검증, 병합, 복사, 정렬, 문구 추천
- `github-sync.mjs`: 인증, UTF-8 변환, SHA 기반 GitHub 동기화
- `interview-data.json`: 사용자가 공개 저장에 동의하고 처음 저장할 때 생성하는 공통 데이터입니다. 아직 없으면 이미 저장소에 있는 `interview-data-backup-2026-09-07.json`을 읽습니다. 새 기기에는 빈 골프존 기업도 준비합니다.
- 이전 JS/TXT와 2026-09-07 백업은 복구 참고용으로 그대로 보존합니다.

## 꼬리질문

- 질문 편집 창의 **꼬리질문 관리**에서 질문·답변·선택 키워드를 추가하고, 위/아래로 순서를 바꿀 수 있습니다. 부모 질문을 저장할 때 함께 저장됩니다.
- **전체 연습 / 중요 질문**에서 기본 답변 아래의 **꼬리질문 N개**를 펼치면 목록이 나옵니다. 각 질문을 눌러 답변을 볼 수 있습니다. 기본값은 접힘이며, 중요 질문이나 연습 문항 수에 별도 문항으로 섞이지 않습니다.
- **실전 연습**은 기본 답변을 확인한 후 꼬리질문을 선택해서 볼 수 있습니다. 다음 문항에서는 다시 접힙니다.
- 검색에는 꼬리질문과 답변·키워드도 포함됩니다. 기업별 JSON 내보내기·가져오기와 GitHub 동기화에도 함께 보존됩니다.
- 데이터 형식은 부모 문항의 선택 필드 `followUps: [{id, question, answer, keywords?}]`입니다. 기존 JSON에는 이 필드가 없어도 됩니다.
- 다른 기업으로 **질문만 복사**하면 꼬리질문도 복사하되 답변·키워드는 비웁니다.

### 읽기와 모바일 화면
- 연습 답변과 꼬리질문은 기본적으로 한국어 구절 경계에 맞춰 호흡 줄바꿈으로 표시합니다. 문맥을 완벽히 분석하는 AI 기능은 아니며, 원문과 내보내기 내용은 변경하지 않습니다. 질문별로 호흡 줄바꿈을 끌 수 있으며, 끄면 직접 입력한 줄바꿈 그대로 표시합니다. 기본 질문과 꼬리질문 각각 설정할 수 있고, 기본값은 켜짐입니다. 설정은 질문의 autoBreathing 필드에 저장되어 JSON 내보내기·가져오기와 GitHub 동기화에 포함됩니다. 이전 브라우저 전체 옵션은 사용하지 않습니다.
- 700px 이하에서는 헤더·기업 목록·기업 관리 영역을 숨깁니다. 하단 기업 메뉴에서 같은 기능을 열 수 있습니다.
- 기업 목록은 등록 순서의 역순으로 표시합니다. 기존 데이터 배열이나 선택 기업은 정렬 때문에 변경하지 않습니다.
